## Типы документов

| Файл | Тип AWI | Структурированные метаданные |
|---|---|---|
| `AGENTS.md` | `agent_instructions` | каталог области, глубина приоритета, заголовки, локальные ссылки |
| `SKILL.md` | `agent_skill` | YAML `name` и `description`, заголовки, локальные ссылки |

Полный ограниченный текст Markdown остаётся доступным для поиска. `workspace_inspect` возвращает структурированные метаданные вместе с обычными метаданными файла и выдержкой содержимого.

## Обнаружение

Обычное согласование рабочей области индексирует файлы `AGENTS.md` и `SKILL.md` под этой рабочей областью с учётом `.gitignore`, `.awiignore` и стандартных исключений AWI.

Установщик первого запуска дополнительно обнаруживает:

- файлы `AGENTS.md` в родительских каталогах над выбранной рабочей областью;
- манифесты `SKILL.md` под известными каталогами проектов и пользователей для поддерживаемых клиентов агентов.

Каждый внешний документ регистрируется как корень одного файла. AWI не индексирует весь домашний каталог или полное содержимое глобальных пакетов Skill. `--skip-agent-knowledge` отключает это дополнительное обнаружение.

Локальные ссылки Markdown из документа агента записываются только тогда, когда их цель существует и остаётся внутри корня документа. Файлы, на которые есть ссылки, доступны для поиска, когда они уже покрыты корнем рабочей области; в противном случае путь ссылки возвращается как метаданные для явной проверки другим файловым инструментом.

## Область и ранжирование

Передайте `context_path` в `workspace_search` при разрешении инструкций репозитория:

```bash
awi search "build and test rules" \
  --kind agent_instructions \
  --context-path /workspace/service/src/main.rs \
  --json
```

AWI исключает файлы `AGENTS.md`, область которых не является предком пути контекста. Применимые файлы ранжируются по глубине области, поэтому ближайшие инструкции идут первыми. После этого ранжирования документы агента с идентичным содержимым сворачиваются, что подавляет скопированные дубликаты Skill и worktree без потери ближайшей применимой инструкции.

Без фильтра типов инструкции Agent и Skills ищутся вместе с кодом и данными. Используйте `--kind agent_skill` или `--kind agent_instructions` только для сужения поиска до одного типа документов Agent. `context_path` включает фильтрацию и ранжирование инструкций по области действия.

## Безопасность

Документы агента по-прежнему подлежат обычным проверкам размера, UTF-8, символических ссылок и конфиденциальных имён файлов. Высоконадёжные шаблоны закрытых ключей и токенов поставщика в их содержимом приводят к результату только с метаданными с `metadata_only_sensitive_content`; содержимое, предварительный просмотр и разобранные метаданные агента не сохраняются.

Неправильно сформированный frontmatter Skill записывается как сбой извлечения, в то время как новое содержимое Markdown по-прежнему заменяет любой более старый индексированный текст. Это позволяет избежать обслуживания устаревшего содержимого, когда только разбор структурированных метаданных завершается неудачей.

## Проверка разработки

Изолированная установка в текущей среде Bona обнаружила 136 канонических документов агента с нулевыми ошибками извлечения. Целевые дымовые запросы выбрали `wukong-dag-failure-debugger` первым для запроса сбоя Wukong DAG/LogID и `AGENTS.md` Bona для контекста источника AWI.

В существующем наборе из 16 случаев разработки добавление этих документов агента сохранило Recall@10 на уровне `1.0`, а частоту устаревших результатов — `0`; MRR изменился с `0.5975` на `0.6027`, nDCG@10 — с `0.6922` на `0.6969`, а P95 сборки релиза — с `8.07 мс` на `25.88 мс`. Задержка остаётся ниже целевого значения `150 мс` для гибридного поиска. Этот набор разработки всё ещё ожидает двойного рецензирования и не является замороженным эталоном релиза.
