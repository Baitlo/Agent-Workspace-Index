## Χρήση

```bash
# Μόνο επιμελημένη μνήμη και περιλήψεις.
awi --index-dir /tmp/my-awi-index memory \
  --project-root /absolute/path/to/workspace

# Ρητή συμπερίληψη αντίστοιχου ακατέργαστου ιστορικού συνομιλίας/συνεδρίας.
awi --index-dir /tmp/my-awi-index memory \
  --project-root /absolute/path/to/workspace \
  --include-raw

# Αναζήτηση μόνο μνήμης που σχετίζεται με το τρέχον έργο.
awi --index-dir /tmp/my-awi-index search "previous deployment decision" \
  --kind agent_memory \
  --context-path /absolute/path/to/workspace \
  --json
```

Ο εγκαταστάτης εκτελεί την επιμελημένη μορφή από προεπιλογή. Χρησιμοποιήστε `--skip-agent-memory` για να την απενεργοποιήσετε ή `--include-raw-memory` για να εγγραφείτε στο ακατέργαστο ιστορικό.

## Πηγές

Η ανακάλυψη περιορίζεται στο επιλεγμένο κανονικό έργο:

| Πράκτορας | Προεπιλεγμένες επιμελημένες πηγές | Ακατέργαστη επιλογή |
|---|---|---|
| Trae | προφίλ χρήστη, αντίστοιχη μνήμη έργου, περιλήψεις θεμάτων, περιλήψεις συνεδριών | τίποτα πέρα από αυτές τις περιλήψεις |
| Codex | `MEMORY.md`, `memory_summary.md`, αντίστοιχες περιλήψεις ανάπτυξης | συνδεδεμένο ακατέργαστο JSONL ανάπτυξης και `raw_memories.md` |
| Zcode | ρίζα μνήμης που αντιστοιχίζεται στο έργο από τα μεταδεδομένα χρόνου εκτέλεσης Zcode | αντίστοιχα αρχεία ανάπτυξης/πράκτορα |
| Gemini CLI | καμία | αντιστοιχισμένο ιστορικό έργου και κατάλογοι συνομιλιών |
| Claude Code | αντίστοιχος κατάλογος μνήμης έργου | αρχεία συνεδρίας που προσδιορίζουν το έργο |

Οι κατάλογοι συνεδριών Argos/SRE αποκλείονται σκόπιμα επειδή απαιτούν τη ροή εργασίας διάγνωσης Argos αντί για μαζική ευρετηρίαση αρχείων. Το AWI δεν σαρώνει ποτέ ολόκληρο τον αρχικό κατάλογο.

## Μεταδεδομένα και Κατάταξη

Κάθε αποτέλεσμα μνήμης περιλαμβάνει:

- Πράκτορα προέλευσης·
- επίπεδο: `user_profile`, `project_summary`, `topic_summary`, `session_summary`, `memory_note` ή `raw_history`·
- προαιρετικά `name` και `description` YAML frontmatter·
- κανονική ρίζα χώρου εργασίας και κλειδί έργου παρόχου όταν είναι διαθέσιμα·
- αναγνωριστικό συνεδρίας όταν μπορεί να παραχθεί·
- χρόνο παρατήρησης και σημαία ακατέργαστου ιστορικού.

Όταν παρέχεται `context_path` ή φίλτρο ρίζας έργου, η μνήμη από άλλο έργο απορρίπτεται. Η μνήμη ακριβούς έργου κατατάσσεται πριν από τη γενική μνήμη. Οι ακριβείς αντιστοιχίσεις ονόματος αρχείου και `name` frontmatter λαμβάνουν την ισχυρότερη ώθηση μεταδεδομένων· η επικάλυψη περιγραφής παρέχει μικρότερη ώθηση. Ερωτήματα σε μορφή αναγνωριστικού υποβαθμίζουν ευρείες περιλήψεις `MEMORY.md`/έργου εκτός εάν η ίδια η περίληψη ταιριάζει ακριβώς με την οντότητα. Η κανονική σειρά επιπέδων παραμένει αμετάβλητη για ευρεία ερωτήματα, οι επιμελημένες περιλήψεις κατατάσσονται πριν από το ακατέργαστο ιστορικό, και η πρόσφατη είναι μόνο μικρός ισοπαλία. Τα αντίγραφα με πανομοιότυπο περιεχόμενο από διαφορετικούς Πράκτορες συμπτύσσονται μετά την κατάταξη. Η ανάκτηση μνήμης ενεργοποιείται με `--kind agent_memory`. Τα έγγραφα μνήμης χρησιμοποιούν ένα αποκλειστικό ευρετήριο Tantivy, επομένως το λεξιλόγιό τους δεν μπορεί να αλλάξει τις κοινές στατιστικές IDF ή την κατάταξη κώδικα/δεδομένων.

## Ανάλυση και Ασφάλεια

Η μνήμη Markdown ευρετηριάζεται ως περιορισμένο κείμενο. Η μνήμη JSON/JSONL κανονικοποιείται σε πεδία σχετικά με τον άνθρωπο όπως πρόθεση, ενέργειες, αποτέλεσμα, μαθεμένα γεγονότα, ρόλο, μήνυμα και περιεχόμενο· τα αναγνωριστικά μεταφοράς και τα εσωτερικά μεταδεδομένα περίληψης παραλείπονται από το έγγραφο αναζήτησης. Η μνήμη JSONL δεν αποστέλλεται σε προφίλ DuckDB.

Οι κανονικοί έλεγχοι μεγέθους, UTF-8, παράβλεψης και ευαίσθητου ονόματος αρχείου εξακολουθούν να ισχύουν. Τα διαπιστευτήρια ή τα ιδιωτικά κλειδιά υψηλής εμπιστοσύνης καθιστούν ολόκληρο το αρχείο μνήμης μόνο μεταδεδομένα. Το ακατέργαστο ιστορικό είναι απενεργοποιημένο εκτός εάν ζητηθεί ρητά, και τα υπερμεγέθη ακατέργαστα αρχεία παραμένουν μόνο μεταδεδομένα υπό το διαμορφωμένο όριο περιεχομένου.

Το `awi memory` διατηρεί την κανονική ρίζα έργου και την πολιτική ακατέργαστου ιστορικού. Κάθε κύκλος παραγωγού επανανακαλύπτει τις πηγές Πράκτορα αυτού του έργου πριν από τη δημοσίευση, επομένως νέοι κατάλογοι έργου παρόχου εμφανίζονται χωρίς επανεγκατάσταση του AWI. Οι προηγουμένως καταχωρημένες ρίζες συμφιλιώνονται επίσης όταν εξαφανίζονται, αποτρέποντας την παραμονή της διαγραμμένης μνήμης αναζητήσιμης. Το προσαρτημένο JSONL περίληψης ανανεώνεται στην επόμενη περιοδική συμφιλίωση· τα αρχεία με έντονη προσάρτηση δεν προκαλούν ανακατασκευές στιγμιότυπων ανά εγγραφή.

Το `awi status --json` εκθέτει ένα αντικείμενο `memory` με καταγεγραμμένους αριθμούς έργου/πηγών, ενεργά αρχεία, τη νεότερη γενιά μνήμης και τη σχετική υστέρηση γενιάς, `stale_files`/`missing_files` του συστήματος αρχείων, μέγιστη υστέρηση πηγής και ηλικία παλαιότερης πηγής. Οι αριθμοί παλαιών και λείποντων αρχείων του συστήματος αρχείων είναι τα αυθεντικά σήματα φρεσκάδας· μια χαμηλή υστέρηση γενιάς από μόνη της δεν αποδεικνύει ότι η εξωτερική μνήμη είναι ενημερωμένη.

## Επικύρωση Ανάπτυξης

Μια απομονωμένη εκτέλεση Bona ανακάλυψε 35 ρίζες σχετικές με το έργο και ευρετηρίασε 489 επιμελημένα αρχεία από Codex, Trae και Zcode με μηδενικές αποτυχίες εξαγωγής· οι ακατέργαστες συνομιλίες Gemini παρέμειναν εκτός. Το υπάρχον σύνολο 16 περιπτώσεων ανάκτησης κώδικα/δεδομένων παρέμεινε σταθερό bit-προς-bit στο Recall@10 `1.0`, MRR `0.6006`, nDCG@10 `0.6950` και ποσοστό παλαιότητας `0`. Το P95 κατασκευής έκδοσης ήταν `24.06 ms`. Αυτό το σύνολο παραμένει `candidate_pending_dual_review`, όχι παγωμένο πύλη έκδοσης. Μην αναφέρετε επίσημη ακρίβεια/ανάκληση, Inspect@K ή MRR έως ότου δύο διακεκριμένοι αξιολογητές επισημάνουν ανεξάρτητα το σύνολο ερωτημάτων και επιδικάσουν τις διαφωνίες.
