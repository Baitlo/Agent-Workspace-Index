## 改动

- **任务级评估**：`audit-call-outcomes.py` schema 2 关联用户轮次、search_id、轮次内全部后续工具及显式最终回答，记录重复搜索和轮次耗时。生成私有评审模板，并接收多个独立评审文件。只有至少两个不同评审者一致的标注进入聚合；单人、分歧、缺失标注分别保留。拒绝 frozen、重复评审和跨任务搜索归因。详见 [评审说明](task-outcome-review.md)。
- **当前工作副本**：源码命中精确文件名或符号时，`context_path` 的最近 Git 工作副本获得小幅优先权，支持 `.git` 文件形式的 linked worktree。明确限定的外部路径仍保留优先权。同名且内容哈希相同的源码合并展示，最多保留三个替代来源；不同内容分别保留并标注。该规则不证明两份源码的运行环境相同。
- **未命中诊断**：最多检查 16 个明确候选路径，不遍历目录。区分范围不存在、范围外、忽略规则、默认排除、符号链接、已索引但未返回、存在但未索引、原因未确定。处理 `.awiignore`、`.ignore`、Git 规则优先级与被裁剪父目录；已确认的 catalog 记录优先于当前忽略规则。全局 Git 配置、无效或超过 64KiB 的忽略文件不做穷尽诊断。
- **证据预算**：`compact_v4` 默认所有命中共 3,000 字符，单条最多 1,000；`preview_chars` 可选 500–20,000。优先给靠前结果分配预算，缩短时保留含查询词的窗口。inspect 默认返回正文附近的 24 个定义，`max_symbols` 可显式展开；正文请求范围不因符号压缩而缩短。
- **版本与交付**：Ping 返回 build identity；审计 schema 7 和工具响应记录 adapter 版本、PID、二进制被替换标记、初始化时观察到的 reader 版本以及通道。默认继续同时交付 text/structured，只有客户端显式协商 `capabilities.experimental.awi.response_channel=structured` 才省略重复正文。`client_receipt=unverified` 始终明确：服务端写出不能证明 GUI 已收到。
