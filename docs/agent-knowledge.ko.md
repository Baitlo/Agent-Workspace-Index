# 에이전트 지식 인덱싱

AWI는 다른 MCP 도구를 추가하지 않고도 소스 코드 및 데이터와 함께 에이전트 운영 지침을 인덱싱합니다.

크로스 에이전트 프로젝트 기록은 `agent_memory`로 별도로 처리됩니다. [크로스 에이전트 메모리 인덱싱](agent-memory.md)을 참조하세요.

## 문서 유형

| 파일 | AWI 종류 | 구조화된 메타데이터 |
|---|---|---|
| `AGENTS.md` | `agent_instructions` | 범위 디렉토리, 우선 순위 깊이, 제목, 로컬 참조 |
| `SKILL.md` | `agent_skill` | YAML `name` 및 `description`, 제목, 로컬 참조 |

전체 제한된 Markdown 텍스트는 검색 가능한 상태로 유지됩니다. `workspace_inspect`는 구조화된 메타데이터와 함께 일반 파일 메타데이터 및 콘텐츠 발췌를 반환합니다.

## 검색

일반 작업 공간 조정은 `.gitignore`, `.awiignore` 및 AWI의 기본 제외에 따라 해당 작업 공간 아래의 `AGENTS.md` 및 `SKILL.md` 파일을 인덱싱합니다.

첫 실행 설치 프로그램은 추가로 다음을 검색합니다:

- 선택한 작업 공간 위의 상위 디렉토리에 있는 `AGENTS.md` 파일;
- 지원되는 에이전트 클라이언트의 알려진 프로젝트 및 사용자 디렉토리 아래의 `SKILL.md` 매니페스트.

각 외부 문서는 단일 파일 루트로 등록됩니다. AWI는 전체 홈 디렉토리나 전역 스킬 패키지의 전체 내용을 인덱싱하지 않습니다. `--skip-agent-knowledge`는 이 추가 검색을 비활성화합니다.

에이전트 문서의 로컬 Markdown 링크는 대상이 존재하고 문서 루트 내에 유지되는 경우에만 기록됩니다. 참조된 파일이 이미 작업 공간 루트에 포함된 경우 검색 가능합니다. 그렇지 않으면 참조 경로가 메타데이터로 반환되어 다른 파일 도구로 명시적 검사가 가능합니다.

## 범위 및 순위

리포지토리 지침을 해결할 때 `context_path`를 `workspace_search`에 전달합니다:

```bash
awi search "build and test rules" \
  --kind agent_instructions \
  --context-path /workspace/service/src/main.rs \
  --json
```

AWI는 범위가 컨텍스트 경로의 상위가 아닌 `AGENTS.md` 파일을 제외합니다. 해당 파일은 범위 깊이별로 순위가 매겨지므로 가장 가까운 지침이 먼저 나옵니다. 이 순위 지정 후 콘텐츠가 동일한 에이전트 문서는 축소되어 복사된 스킬 및 워크트리 중복을 억제하면서 가장 가까운 적용 가능한 지침을 잃지 않습니다.

스킬 중심 검색에는 `--kind agent_skill`을 사용합니다. 에이전트 문서는 일반 코드/데이터 검색에서 제외됩니다. 전용 에이전트 레인은 에이전트 종류 필터 또는 `context_path`에 의해 활성화됩니다.

## 안전

에이전트 문서는 일반 크기, UTF-8, 심볼릭 링크 및 민감한 파일 이름 검사의 대상으로 유지됩니다. 콘텐츠의 고신뢰도 개인 키 및 공급자 토큰 패턴은 `metadata_only_sensitive_content`가 있는 메타데이터 전용 결과를 유발합니다. 콘텐츠, 미리 보기 및 구문 분석된 에이전트 메타데이터는 저장되지 않습니다.

잘못된 형식의 스킬 frontmatter는 추출 실패로 기록되지만 새 Markdown 콘텐츠는 여전히 이전 인덱싱된 텍스트를 대체합니다. 이렇게 하면 구조화된 메타데이터 구문 분석만 실패할 때 오래된 콘텐츠가 제공되는 것을 방지할 수 있습니다.

## 개발 검증

현재 Bona 환경에서의 격리된 설치는 136개의 정식 에이전트 문서를 발견했으며 추출 실패는 0건이었습니다. 대상 스모크 쿼리는 Wukong DAG/LogID 실패 쿼리에 대해 `wukong-dag-failure-debugger`를 먼저 선택하고 AWI 소스 컨텍스트에 대해 Bona `AGENTS.md`를 선택했습니다.

기존 16개 사례 개발 검색 세트에서 이러한 에이전트 문서를 추가해도 Recall@10은 `1.0`, 오래된 결과율은 `0`으로 유지되었습니다. MRR은 `0.5975`에서 `0.6027`로, nDCG@10은 `0.6922`에서 `0.6969`로, 릴리스 빌드 P95는 `8.07 ms`에서 `25.88 ms`로 변경되었습니다. 지연 시간은 `150 ms` 하이브리드 검색 목표 미만으로 유지됩니다. 이 개발 세트는 이중 검토 대기 중이며 동결된 릴리스 벤치마크가 아닙니다.
